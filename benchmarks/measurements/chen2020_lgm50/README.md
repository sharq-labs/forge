# Chen 2020 LG M50 validation discharges (vendored)

Three LG M50 cells, CC-CV charge to 4.2 V then CC discharge to 2.5 V at C/10, C/2, 1C and 1.5C, with cell-surface and
chamber temperature, 30 s sampling. Zenodo 10.5281/zenodo.4032561, CC-BY-4.0; please cite Chen et al.,
J. Electrochem. Soc. 167 (2020) 080534.

`raw/` holds the files byte for byte as published (`.gitattributes: * -text`, so git never rewrites them);
`manifest.json` pins each by sha256 and md5. Used by the BIG 14 flagship A validation study
(`flagships/forge_flagships/data/big14_a_lgm50_validation_preregistration.json`).
