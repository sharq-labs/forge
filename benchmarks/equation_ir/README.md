# Equation IR dimensional corpus

This benchmark is a deterministic **dimensional-algebra regression corpus** for
the universal Equation/Law IR. It is not a claim that 500 cases prove scientific
truth.

The single committed `cases.json` corpus contains 500 deterministic cases generated by `generate_cases.py` and split as:

- 100 dimensionally valid additions,
- 100 invalid additions across incompatible base dimensions,
- 100 products,
- 100 ratios,
- 50 exact integer powers,
- 25 valid dimensionless transcendental-function calls,
- 25 invalid dimensional arguments to transcendental functions.

The tests require all 500 files to be present, unique, reproducible from the
generator, and to produce the declared dimensional outcome through the real
Equation IR implementation.
