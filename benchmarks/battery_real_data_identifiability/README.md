# Battery Practical Pass 1: real-data ingestion and the 1RC identifiability gate

Generated by `audit/run_pass1.py` from the vendored raw bytes in
`benchmarks/battery_flagship_b3/evidence/raw/` (Jahn 2024, Zenodo 10.5281/zenodo.11958572, CC BY 4.0).
The code is `engcore.domains.battery.real_data`. Nothing here calibrates, validates or
counts as evidence.

| File | What it is |
|---|---|
| `RECEIPT.json` | Immutable dataset receipt. It holds the byte pins, the format, the parser and normalization versions, the normalized-content digests, the lineage, the consistency checks and the declared assumptions. |
| `QUALITY.json` | Deterministic quality report per file: segments, transitions, sampling, ranges, flags. It classifies samples and never cleans them. |
| `SPLIT.json` | Test-sequence split bound to the receipt. The cell is shared, so the split's scope is within-cell only. |
| `IDENTIFIABILITY_GATE.json` | The gate's decision for `battery.thevenin_1rc` on the calibration group only. Its parameter values are diagnostic linearization points. |

Reproduce, or check the committed files against a fresh run:

```bash
python benchmarks/battery_real_data_identifiability/audit/run_pass1.py
python benchmarks/battery_real_data_identifiability/audit/run_pass1.py --check
```
