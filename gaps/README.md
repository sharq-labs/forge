## تحسينات Multiphysics العامة الثلاثة

1. **عقد الكمية المنقولة:** المعنى والوحدة وموقع الحقل وإطاره ووقت صلاحيته وما يجب حفظه. القبول: رفض عدم التوافق دون شروط باسم الدومين. مرتبط بـR03 وG02.
2. **تقارب المشاركين والربط:** تسجيل تقارب الحل الداخلي والروابط والاتزان كلًا على حدة؛ تحقق أحدها لا يغني عن البقية. القبول: فشل داخلي لا يختفي خلف تقارب الحلقة. مرتبط بـC02 وC05 وR04.
3. **العقد الزمني:** طريقة قراءة البيانات داخل النافذة وخطوات المشاركين والأحداث والاستعادة. القبول: مقارنة بمرجع زمني أدق ورفض بيانات خارج وقت صلاحيتها. مرتبط بـC10 وR10 وG07.

## نقل اقتراح إلى التنفيذ

ابدأ بجرد الكود والاختبارات عند SHA جديد، ثم حدّد counterexample أو حاجة مستخدم، والنطاق والمالك ومعيار القبول. أدخل slice في الخطة الفعلية وفق الأولويات المصرح بها. لا تبنِ Evidence أو Uncertainty أو Provenance موازية، ولا تعدّل شهادة أو معيار قبول لتجاوز إخفاق.

تحسين عام لا يعني وضعه كله داخل Scientific Core: واجهات الإدخال والتقارير أعلى العقود؛ العلاقات العلمية يملكها الدومين؛ MCP ناقل فقط. UNKNOWN لا يصبح صفرًا، التقارب ليس validation، والاقتراح لا يضمن دعمًا علميًا.
