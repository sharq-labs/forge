# v1.0-core-freeze — Core Freeze V1

**Read this paragraph before any number below it.** This tag freezes the Core's
public *contract*, not its behaviour and not its performance. It freezes
exactly **194** public symbols and deliberately excludes **11** experimental
ones. The first freeze candidate was **blocked**: the written serialization
policy said no legacy format was supported, while eight frozen readers accept
older versions and are tested doing so. The fix was a docstring, `src/` is
byte-identical to the Sprint 10 close, and every assurance step ran on the
corrected candidate rather than being carried across. The full account is
`certification/CORE_FREEZE_V1.md`.

## What is frozen, in one line each

- the 194 symbols exported from `engcore.scientific`, `.data`, `.inference`,
  `.uq`, `.adequacy`, `.execution`, `.studies` and classified FREEZE;
- their signatures, parameter kinds, defaults, dataclass fields and default
  factories, enum members, exception ancestry;
- 61 round-trippable records, 16 export-only, and the legacy table of 8 readers;
- identity semantics: material changes move a digest, non-material ones do not;
- declared ordering of sweep outcomes and failures;
- seven exception roots;
- `engcore` as the one package identity, and the installed wheel matching source.

## What is not

The 11 experimental symbols (`engcore.studies`: 8; `engcore.inference`
field-observation: 3), behaviour and numbers, performance, error prose,
internals, the non-Core packages, and the `workers` parameter. EI/RI/FM/SP were
carried forward, not re-measured, and nothing here rests on them.
