## 3. Conservation derivation and error limits

For capacity C_i, represented old/new temperatures, inward boundary powers b and source powers p, the backward-Euler finite-volume row is

`C_i (Tnew_i - Told_i) = dt (Fleft_i - Fright_i + p_i + b_i)`.

Shared internal face powers cancel in the sum. Define `D = sum C_i*(Tnew_i-Told_i)`, `B = dt*(b0+b1)`, `S = dt*sum p_i`, `R = D-B-S`. A discrete global conservation residual is distinct from local linear residual, physical/model discrepancy and spatial/temporal truncation error. Truncation error affects solution accuracy; it does not justify an arbitrary discrete energy leak.

The former global arithmetic floor `64*eps*dt*sum(abs(A)@abs(T)+abs(rhs))` includes absolute internal conductance terms. On a uniform fixed-length mesh, conductance scales as N and there are O(N) rows, hence approximately N² even at uniform temperature with zero physical face exchange. The historical 1e-7J leak became admissible at256/512 cells. Raising precision in the exchange sum alone cannot fix that independent allowance.

Under the owner-approved policy, `F(x)=Fraction.from_float(float(x))` evaluates each finite represented input exactly. The global criterion is

`abs(D-B-S) <= F(atol) + F(rtol)*X`,

`X = max(sum(abs(C_i*(Tnew_i-Told_i))), F(dt)*(abs(b0)+abs(b1)+sum(abs(p_i))))`.

All these products, differences, sums and the comparison use rational arithmetic. Interior face-power magnitudes are excluded; internal redistribution remains represented by sum|C_i*deltaT_i|. Existing positive declared atol/rtol remain; exact equality is not required. No unproved global solver-roundoff allowance is added. The original matrix allowance remains only an additional local residual condition and cannot override global refusal.
