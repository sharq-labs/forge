# Audit documents

Files in this directory are **historical snapshots**, not automatically current architecture truth.

For current structure start at [../architecture/README.md](../architecture/README.md). For executable truth use `src/engcore/`, tests, benchmarks and certification records.

Examples:
- `CORE_INTELLIGENCE_LAYER_2026-09-18.md` records the state after PRs #51-#56; later PRs changed several findings.
- `CORE_REAUDIT_2026-09-16.md` is a detailed historical re-audit.
- `SCIENTIFIC_DECISION_READINESS_*.md` records sprint-by-sprint decision-readiness history.

Do not rewrite an old audit to look current. Add a newer audit or update the current architecture documentation instead.
